# ミライ投資ラボ

小学5年生〜中学生向け、投資 × 日本社会を学ぶブラウザーゲーム。無料・登録不要。本物のお金は使用しません。

## 遊び方

1. 6年分の架空ニュースを読みます（円安、少子高齢化、税、金利、エネルギー、技術）。
2. 公共予算の重点と、個人の架空資産10万円の配分を選びます。
3. 1年進めて、総資産・物価を考慮した購買力・社会への影響を確認します。
4. 解説付きクイズで振り返ります。最後に記録をMarkdownで保存できます。

やさしい説明と中学生向けの追加解説を切替可能。端末内自動保存、キーボード操作、スマートフォン対応。

## 開発

Node.js 22以上。ランタイム依存パッケージなし。

```sh
npm run dev
npm test
npm run build
```

開発サーバー: http://127.0.0.1:4173 。ビルドは公開用の5ファイルだけを `dist/` にコピーします。Vercelは `vercel.json` の設定で静的配信します。

## モデルの範囲

各年、総資産を10%単位で再配分。株のリターンはテーマごとの基本値に最大±9ポイントの擬似乱数を加算。同じセーブでは結果を再現します。利益を翌年に再投資し、累積の物価倍率で購買力を算出。国債は毎年満期の架空の商品です。税金・手数料・配当の別計算や途中売却は省略。政策選択による社会指標は架空の学習用で、個人資産とは独立しています。

将来の予測、個別商品の推奨、現実の政策効果の試算ではありません。出典と詳細はアプリ内「参考資料・モデルについて」に記載。

## プライバシー

アカウント・個人情報の入力なし。進行はlocalStorageのみ。広告・アクセス解析なし。VercelとGoogle Fontsへの通常の接続情報は各サービスに送信されます。共有端末の進行はリセット可能。
